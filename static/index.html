Lấy access_token thế nào?
  1. Mở udemy.com trên trình duyệt, đăng nhập.
  2. Bấm F12 → tab Application (Chrome/Edge) hoặc Storage (Firefox) → Cookies → https://www.udemy.com.
  3. Tìm dòng access_token, copy cột Value và dán vào ô trên.
  4. Nếu bị báo Cloudflare chặn: tab Network → bấm 1 request tới udemy.com → copy nguyên giá trị header Cookie và dán vào.
